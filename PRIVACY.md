# AutoForm privacy policy

_Last updated: [DATE]. Replace bracketed text before publishing._

AutoForm helps you fill web forms from a profile you create. This page explains what data it handles.

## What is collected

- **Profile data you enter.** This includes your name, contact details, education, work experience, skills, projects, previously approved answers, and text extracted from a CV you upload. The original CV file is not stored.
- **Form field descriptions.** When you click the AutoForm button on a page, the extension sends the labels, names and options of that page's form fields to the AutoForm server. This lets the server suggest which saved value belongs in each field. The description includes any text already entered in those fields. Password and file fields are never read.
- **An anonymous access key.** The extension creates it on first use to keep your data separate from other users. No email address or password is required.

AutoForm does not collect browsing history, does not run on pages until you open it, and does not submit forms.

## How data is used

- To suggest values for form fields and fill the ones you approve.
- To draft answers to written questions when you ask for one. The question and the relevant parts of your profile are sent to our language-model provider, [Groq, Inc. (https://groq.com/privacy-policy/)], to generate the draft. The provider handles this data under its own policy.

Data is not sold, used for advertising, or shared with anyone else.

## Your control

- **Edit or delete** any record from the profile dashboard (AutoForm icon → *Edit profile*).
- **Delete everything** with *Settings → Delete all my data*.
- Uninstalling the extension removes the access key from your browser. Data left on the server can no longer be reached without the key. To have it removed, delete it before uninstalling or contact us.

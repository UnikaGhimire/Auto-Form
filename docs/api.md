# API

Interactive documentation is available from FastAPI at `/docs` while the service is running.

Key routes: `GET /health`, `GET|PUT /profile`, CRUD routes for `/education`, `/experience`, `/projects`, `/skills`, and `/answers`; `POST /cv/upload`; `POST /fields/classify`; `POST /answers/generate`; and `POST /settings/delete-all-data` with an explicit confirmation body.
